# Tarea 4 — Notebook de métricas de clasificación

## Descripción

Esta tarea tiene como objetivo desarrollar y evaluar un modelo de regresión logística utilizando el conjunto de datos Bank Marketing, disponible en el UCI Machine Learning Repository. El dataset contiene información sobre campañas de marketing telefónico cuyo propósito era conseguir que los clientes contrataran depósitos a plazo fijo.

El dataset contiene 41,188 registros y 20 atributos relacionados con información de los clientes, contactos previos e indicadores económicos. Además, incluye la variable objetivo `y`, que indica si un cliente aceptó (`yes`) o rechazó (`no`). 

El objetivo principal de la tarea es evaluar el rendimiento de la regresión logística mediante distintas métricas de clasificación y determinar cómo influye la elección del umbral de decisión

## Requisitos

El proyecto fue desarrollado en Python y requiere las siguientes bibliotecas:

- Python 3
- pandas
- NumPy
- Matplotlib
- scikit-learn
- Jupyter Notebook

Las dependencias pueden instalarse con:

pip install pandas numpy matplotlib scikit-learn jupyter

## Ejecución

1. Descargar o clonar los archivos de la tarea.
2. Colocar `bank-full.csv` en la misma carpeta que `Tarea 4.ipynb`.
3. Abrir el notebook utilizando Jupyter Notebook o JupyterLab.
4. Ejecutar las celdas en orden desde el inicio.
