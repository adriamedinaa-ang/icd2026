# Tarea 2 Preprocesamiento de Datos

## Descripción

En esta práctica se aplican diferentes técnicas de preprocesamiento al dataset **Breast Cancer Wisconsin**. 

## Dataset

El archivo utilizado contiene **699 registros y 11 atributos**, incluyendo un identificador de muestra, nueve características celulares y la variable objetivo `Class`.

La variable `Class` utiliza los siguientes valores:

- `2`: tumor benigno.
- `4`: tumor maligno.


## Contenido del análisis

El notebook incluye las siguientes etapas:
1. **Limpieza de datos**
2. **Reducción de dimensionalidad por PCA**
## Requisitos de ejecución

Para ejecutar el notebook se requiere **Python 3** y las siguientes librerías:

- pandas
- NumPy
- Matplotlib
- scikit-learn

Las dependencias pueden instalarse mediante:

pip install pandas numpy matplotlib scikit-learn

## Instrucciones de uso

1. Descargar el notebook y el archivo correspondiente al dataset.
2. Colocar ambos archivos en el mismo directorio o modificar la ruta de carga del dataset dentro del notebook.
3. Abrir el notebook utilizando Jupyter Notebook, JupyterLab o Google Colab.
4. Ejecutar las celdas en orden para reproducir el proceso completo de limpieza, preprocesamiento y reducción de dimensionalidad.
