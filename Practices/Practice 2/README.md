# Práctica 2: Preprocesamiento de datasets

## Descripción

Esta práctica se realizó un preprocesamiento de datos utilizando información relacionada con el riesgo de diabetes en población mexicana.

El dataset fue construido a partir de información pública de la **Encuesta Nacional de Salud y Nutrición (ENSANUT) 2024**, publicada por el Instituto Nacional de Salud Pública (INSP). Incluye variables demográficas, antropométricas y bioquímicas que permiten analizar diferentes factores relacionados con el riesgo de diabetes.

El objetivo principal de la práctica es preparar los datos para su posterior. 

## Procedimientos realizados

Durante la práctica se realizaron las siguientes etapas:

- Exploración inicial y análisis de la estructura del dataset.
- Limpieza de datos
- Extracción de características
- Aumento de datos
- Selección de características
- Reducción de dimensionalidad


## Variable objetivo

La variable objetivo utilizada es `riesgo_diabetes_cat`, que representa las diferentes categorías de riesgo de diabetes presentes en el dataset.

## Requisitos

La práctica fue desarrollada en **Python 3** mediante Jupyter Notebook. Las principales librerías utilizadas son:

- pandas
- NumPy
- Matplotlib
- Seaborn
- scikit-learn
- imbalanced-learn

Las dependencias pueden instalarse mediante:

    pip install pandas numpy matplotlib seaborn scikit-learn imbalanced-learn

## Ejecución

1. Descargar o clonar el proyecto.
2. Instalar las librerías necesarias.
3. Colocar el dataset en la ubicación indicada dentro del notebook.
4. Abrir el archivo `.ipynb` mediante Jupyter Notebook, JupyterLab o un entorno compatible.
5. Ejecutar las celdas en orden, ya que algunas etapas dependen de los resultados obtenidos previamente.
